# A Place at the Table

Entry for [Make the AI Judge Feel Proud: A Family Scene](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2) — a one-or-two-line family scene, warm, funny and heartfelt, judged head-to-head by an AI judge.

`main.ts` writes the scene to `/output/entry.txt`:

> Our robot vacuum finally learned the dog's name.
> So tonight Dad thanked it at dinner, Mum set it a place at the table, and nobody laughed — we were all too proud.

The scene is 164 characters over two lines, inside the 280-character gate. The joke lands on a real domestic moment — a household that has quietly adopted its robot vacuum as family — and the warmth comes from nobody laughing: they are all too proud. A small nod to the judge itself, which is also a machine being welcomed to the table.

Run it with Node 22+: `node main.ts`. It is fully deterministic — the same bytes every run.
